# 工时表导出分区

原型接收包含员工、日期、开始和结束时间以及可选公共假日标记的 CSV 文件，每行是一班。测试只使用合成姓名。基准选择逗号、ISO 日期、24 小时时间、LF、无 BOM、单行；每次改变一个类别。引号内的逗号和分隔符有交互，另设测试。跨午夜测试日期与时刻的关系。上表列出 产品导入器应支持的分区，以及必须给出明确错误的分区。产品导入器应采用维护中的 CSV 解析器实现完整引号规则和流式处理；引号内换行超出本原型契约，需要在产品导入器中明确决定。

| 变量 | 产品导入器支持 | 明确拒绝 |
| --- | --- | --- |
| 分隔符 | 逗号、分号、制表符，由表头决定 | 文件中混用分隔符 |
| 表头 | employee/employee name/staff；date/shift date；start/start time；end/end time，不区分大小写 | 未知或缺失表头 |
| 日期 | ISO `yyyy-MM-dd`、澳大利亚 `d/M/yyyy`，严格校验 | 非法日期或其他格式 |
| 时间 | 24 小时 `HH:mm`、12 小时 `h:mm AM/PM` | 非法时间 |
| 公共假日 | 可选列 `public holiday`/`public_holiday`/`holiday`；true/yes/1 或 false/no/0/空值，不区分大小写；缺省为 false | 其他值 |
| BOM | 文件开头允许 UTF-8 BOM | 数据中出现 BOM |
| 引号 | 引号中的逗号、双引号转义 | 引号未闭合 |
| 行 | 忽略空行 | 列数错误、员工姓名为空 |
| 换行 | CRLF 或 LF | 单独 CR |
| 班次 | 结束时间早于开始时间则为次日 | 起止相同、超过 24 小时 |
